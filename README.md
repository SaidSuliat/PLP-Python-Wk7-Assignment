# Analyzing Data with Pandas and Visualizing Results with Matplotlib

## Overview

This project demonstrates how to load, explore, analyze, and visualize data using the **Pandas**, **Matplotlib**, and **Seaborn** libraries in Python. The **Iris dataset** is used for this purpose.

---

## Contents

- `data_analysis_visualization.py`: The main Python script for loading and analyzing the dataset and generating visualizations.
- `line_chart.png`: Cumulative sepal length plot by species.
- `bar_chart.png`: Average petal length by species.
- `histogram.png`: Distribution of sepal width.
- `scatter_plot.png`: Relationship between sepal length and petal length.
